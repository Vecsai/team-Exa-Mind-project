# RACI-матрица распределения ответственности

## Расшифровка RACI

- **R (Responsible)** — выполняет работу.
- **A (Accountable)** — отвечает за конечный результат (всегда один).
- **C (Consulted)** — консультирует, даёт советы.
- **I (Informed)** — информируется о результатах.

## Пояснения к матрице

### Создание и настройка репозитория
Отвечает и выполняет руководитель. Архитектор помогает технически.
Остальные информируются.

### Поддержание структуры
Ответственный — руководитель. Выполняют все участники для своих разделов.
Руководитель следит за соблюдением единой структуры.

### Написание отчётов
Ответственный — руководитель. Выполняют все участники согласно своим ролям.
Каждый пишет свою часть отчёта.

### Проверка Pull Request
Ответственный — руководитель. Выполняют: архитектор (технические PR),
тестировщик (качество), исследователь (текстовые части).
Руководитель проверяет все PR.

### Слияние веток
Ответственный и выполняющий — руководитель. Архитектор помогает.
Остальные информируются.

---

## Принципы работы с матрицей

1. По каждой задаче должен быть **ровно один A** — иначе возникает
   безответственность.
2. Если участник указан как **R**, он обязан выполнить работу в срок.
3. Если участник указан как **C**, к нему обращаются за советом.
4. Если участник указан как **I**, он получает уведомление о результате.
5. Матрица может уточняться по ходу проекта по согласованию с командой.

---

## Заключение

RACI-матрица позволяет чётко распределить ответственность и избежать
ситуаций, когда задача «висит в воздухе» или выполняется несколькими
участниками без согласования. Использование матрицы повышает прозрачность
работы команды и облегчает контроль сроков.
